Java Calculator

About the Project

This is my first Java project. It is a simple, menu-driven calculator that performs basic arithmetic operations.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- User input using Java Scanner

Technologies Used

- Java
- Scanner class
- Switch-case statements
- Conditional statements

How to Run

1. Install the Java Development Kit (JDK).
2. Save the source code as "Main.java".
3. Compile the program using "javac Main.java".
4. Run it using "java Main".
5. Enter two numbers and choose an operation.

- Variables and data types
- Switch-case statements
- If statements
- Basic arithmetic operations
- Testing a Java program
